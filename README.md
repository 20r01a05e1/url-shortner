🔗 URL Shortener

A simple and efficient URL Shortener built using Python, Flask, and SQLite. The application generates unique short URLs for long links and redirects users to the original destination instantly.


Features-

- 🔗 Generate unique short URLs
- 🌐 Redirect short URLs to original links
- 💾 Store URL mappings using SQLite
- ⚡ Fast and lightweight Flask backend
- 🎨 Responsive user interface with HTML, CSS & Bootstrap
- 🔄 Prevent duplicate URL entries
- 📱 Simple and user-friendly design


🛠️ Tech Stack

- Backend: Python, Flask
- Database: SQLite, SQLAlchemy
- Frontend: HTML, CSS, Bootstrap
- Version Control: Git & GitHub
- Deployment: PythonAnywhere

🌍 Usage

1. Open the application in your browser.
2. Enter a valid long URL.
3. Click Shorten.
4. Copy the generated short URL.
5. Open the short URL to be redirected to the original website.
